# Business_Insights_360_-AtliQ
Developed an interactive Business Insight 360 dashboard in Power BI covering Finance, Sales, Marketing, Supply Chain and Executive analytics. Analyzed $43.54B Net Sales, 36.97% Gross Margin, -17.49% Net Profit and 84.38% Forecast Accuracy using DAX, Power Query, data modeling and interactive visualizations to generate actionable business insights.
